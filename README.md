# FPS Shooter 🏗️ (Work in Progress)

An immersive, solo-developed First Person Shooter built in Unity 6. This project focuses on tight gunplay mechanics and AI-driven zombie combat.

---

## 🚀 Current State
The core foundation of the game is complete. I am currently refining the AI systems and expanding the world-building.

### ✅ What's Done So Far
* **Core Movement:** Fully implemented FPS controller (Walking, Sprinting, Camera Control).
* **Combat System:** Firing mechanics for **4 unique gun types**.
* **Assets:** All **3D models and environment assets** are integrated.
* **Level Design:** **3 playable levels** are currently built and textured.
* **Enemy AI:** Initial Zombie AI with automated player tracking and basic pathfinding.

---

## 🛠 Tech Stack
* **Engine:** Unity 6000.2.14f1
* **Language:** C#
* **Platform:** PC
